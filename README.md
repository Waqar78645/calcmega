# CalcMega

**Live site: [https://calcmega.com](https://calcmega.com)**

CalcMega is a free hub of 100+ online calculators — financial (mortgage, auto loan, refinance, rent, interest rate, credit card payoff), fitness & health, math, everyday utilities and unit converters. Every calculator runs privately in the browser and comes with a plain-English guide showing the formula and a worked example.

- 📖 Guides: https://calcmega.com/blog
- ℹ️ About: https://calcmega.com/about
- ✉️ Contact: https://calcmega.com/contact

Built with static HTML/CSS/JavaScript, hosted on nginx. New calculators go live in daily batches with their guides.
